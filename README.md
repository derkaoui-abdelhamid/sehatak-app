# 🩺 Sehatak App (Your Health)

**Sehatak** is an interactive medical assistant web application specifically designed for users in **Algeria**. It provides preliminary medical diagnosis, detailed health insights, and connects users with local healthcare providers based on their symptoms and province.

---

## 🌟 Key Features
* **58 Wilayas Coverage:** Full support for all 58 Algerian provinces.
* **Smart Diagnosis:** Keyword-based analysis for various symptoms (Headache, Flu, Gastritis, Anemia, etc.).
* **In-depth Medical Insights:** Explains the physiological causes of symptoms and differential diagnosis.
* **Natural Recovery Protocols:** Detailed home remedy suggestions using locally available herbs (e.g., Eucalyptus, Thyme, Pomegranate peel).
* **Dynamic Google Maps Integration:** A one-click feature that opens Google Maps to find the nearest specialists or hospitals in the user's specific city.

---

## 🛠️ Tech Stack
* **HTML5:** Structured the application layout.
* **CSS3:** Styled with a clean, medical-themed, and responsive UI (Tajawal Google Font).
* **JavaScript (Vanilla):** Engineered the medical logic engine, city population script, and dynamic Maps URL generation.

---

## 🚀 How It Works
1.  **Select Location:** Choose your province (Wilaya) from the dropdown list.
2.  **Describe Symptoms:** Type how you feel in the text area (e.g., "I have a sharp headache").
3.  **Analyze:** Click the "Analyze Case" button.
4.  **Get Results:** The app displays:
    * A detailed medical report.
    * A step-by-step natural treatment plan.
    * A direct button to find specialized doctors on **Google Maps** within your city.
